# ytma
YouTube Metadata Analytics toolchain

This collection of notebooks can be used with data retrieved from the YouTube API with the help of [PYG lean](https://github.com/zoomingmediaresearch/pyg-lean).
In order to set the tools up, please download to a working directory and create a folder called 'output' in your working directory. In my own setup, the pyg data is contained in folders within the working directory.

Important!
The current version of pgy lean creates individual files for each language. Please combine these files into one Zip file in order to use with this toolchain. I hope to modify pgy lean to return compressed archives soon.
